# chod-lite

Lżejsza wersja strony "Chłopaki od dźwięku" zbudowana w Astro.

## Wymagania

- Node.js (zgodnie z plikiem `.node-version`)
- npm

## Uruchomienie w trybie deweloperskim

1. Wejdź do folderu projektu:

   ```bash
   cd chod-lite
   ```

2. Zainstaluj zależności:

   ```bash
   npm install
   ```

3. Uruchom serwer deweloperski:

   ```bash
   npm run dev
   ```

4. Otwórz stronę w przeglądarce:

   ```
   http://localhost:4321/
   ```

## Build produkcyjny

Aby wygenerować statyczną wersję strony:

```bash
npm run build
```

Wynik budowania znajdzie się w folderze `dist/`.
